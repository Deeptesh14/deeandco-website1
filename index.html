The Framework

Three stages. Each conditional on the previous. Nothing skipped.

01

Evaluate.

An honest written assessment including what is not ready. If we would not invest, we say so before anything else happens.

02

Position.

The narrative, documents, and financial architecture built to answer every serious question before it is asked.

03

Match.

An introduction made only when thesis, portfolio, and timing align. We introduce on precision, not probability.
